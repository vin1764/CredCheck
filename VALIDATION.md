# CredCheck validation report

Generated by `python validation.py` on the simulated 12,000-firm dataset
(60/20/20 split: 7,200 train, 2,400 calibration, 2,400 test).

## 1. Does missing data predict default?

CredCheck's design assumes a missing evidence source signals uncertainty, not risk.
This checks that assumption instead of taking it on trust.

| Source | Firms missing it | Default rate if present | Default rate if missing | Difference | p-value | Verdict |
| --- | --- | --- | --- | --- | --- | --- |
| Trade history | 1,089 | 18.3% | 18.5% | +0.3 pts | 0.812 | no risk signal |
| GST | 1,630 | 18.0% | 20.0% | +2.0 pts | 0.054 | borderline: re-test on real data |
| Bank statements | 0 | 18.3% | — | — | — | never missing |
| Credit bureau | 2,298 | 18.2% | 18.8% | +0.7 pts | 0.441 | no risk signal |
| Financial statements | 6,516 | 18.4% | 18.2% | -0.2 pts | 0.728 | no risk signal |

Adding "source missing" flags to a logistic regression: test AUC 0.810 without,
0.810 with. A model using only the missing flags scores AUC 0.490
(0.5 = no signal).

**Reading it:** on this simulated data, missingness carries no meaningful risk signal, as
designed: blanks were generated by legal structure, not by risk, and the missing flags add
nothing to a model. Any borderline row is chance at this sample size. On a real lender's book, run this
first. If a source's absence does predict default, add its missing flag as a feature so the
model learns that risk instead of ignoring it.

## 2. Benchmark on the same split

All models are trained on the same 7,200 firms, calibrated with isotonic regression on the
same 2,400 firms, and scored on the same 2,400 test firms.

| Model | Test AUC | Brier (lower is better) |
| --- | --- | --- |
| True PD (best possible on this data) | 0.858 | 0.100 |
| Logistic regression + missing flags | 0.810 | 0.116 |
| Logistic regression (median fill) | 0.810 | 0.116 |
| CredCheck, logistic-regression experts | 0.804 | 0.117 |
| Random forest, 500 trees (median fill) | 0.797 | 0.122 |
| HistGBM, one model on all 13 features | 0.780 | 0.125 |
| CredCheck, HistGBM experts (default) | 0.779 | 0.125 |

**Reading it:** logistic regression scores highest because the simulated risk is linear
(each feature is a hidden driver plus noise), which is exactly what logistic regression
assumes. The CredCheck architecture works with either expert; switch with
`CredCheckModel(expert="logreg")`. Gradient boosting stays the default because real credit
data usually has thresholds and interactions that the simulation does not.

## 3. Decline rule and the thin-file limit cut

A firm is declined when its calibrated PD × LGD (60%) exceeds 15%,
i.e. a PD above 25%. The rule uses the calibrated PD only, so missing
data never causes a decline by itself.

| Decision | Share of test firms | Actual default rate |
| --- | --- | --- |
| Approved | 79% | 11.4% |
| Declined | 21% | 44.8% |

**Thin-file limit cut.** Among approved firms with confidence below 70%
(33 test firms), limits are on average **13%** lower than the same firms would
get with complete data (range 10% to 20%; 13% of total limit
value). The cut comes from missing data alone; the PD and the decision are unchanged.
